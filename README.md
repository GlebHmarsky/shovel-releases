# Shovel Windows downloads

Windows installers and signed update feeds for Shovel, published by GlebHmarsky.

For the first online update test, install version 0.30.103 and use Help > Shovel updates to download 0.30.104. The older Shovel Local Test is offline-only.

Windows publisher signing is not yet configured. Source repository: https://github.com/GlebHmarsky/Shovel (currently private).
